what it does

One template gives every repo gates, hooks and guides from day one

Repo instantiation

One script creates a repo; a sync tool reapplies updates to existing ones.

Lifecycle sensors

Lint, tests, coverage, BDD, mutation and security scans at each stage.

Agent runtime harness

Hooks block risky git moves and gate edits; checks run before an agent says done.

Incident-based fitness tests

Architecture tests that each trace back to a failure the fleet really had.

Config conformance lint

Catches broken CI paths, stale owners and leftover placeholders early.

Incident protocol

Every escaped failure ends with a fix, a new sensor and a fleet rollout.
